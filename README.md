# Análisis de Rendimiento de Asistentes

## Descripción
Dashboard desarrollado en Power BI para analizar el rendimiento de asistentes mediante indicadores de proyectos, valorizaciones y metrados.

## Herramientas
- Power BI
- DAX
- Power Query
- Excel

## Indicadores
- Total valorizado
- Proyectos por asistente
- Metrado valorizado
- Índice de equidad
- Balance de carga
